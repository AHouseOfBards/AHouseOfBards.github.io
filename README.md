# ahouseofbards.github.io

Keeps old plugin repository links working after a rename.

`Bonfire-JellyProfiles/manifest.json` is Bonfire's stable manifest, at the address servers
added before the Bonfire repository was renamed. A workflow copies it from Bonfire's main
branch every hour.

To install Bonfire, use Campground's repository instead:
https://ahouseofbards.github.io/Campground-Jellyfin/manifest.json
